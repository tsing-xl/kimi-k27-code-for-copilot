Kimi K2.7 Code for Copilot Chat uses your own Kimi API key to make Kimi models available in the model picker.

Paste it once, then update or remove it later from the Command Palette.

- `Cmd/Ctrl + Shift + P`: Open the Command Palette
- `Kimi K2.7 Code: Set API Key`: Set or update your API key
- `Kimi K2.7 Code: Clear API Key`: Remove your API key
- `Kimi K2.7 Code: Get API Key`: Create a Kimi API key
